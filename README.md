* **Automated Occupancy Detecting AC Control System:** Developed an occupancy-based AC control system to improve energy efficiency by automatically adjusting AC operation based on room occupancy[cite: 1]. Designed and validated the control logic in MATLAB/Simulink using discrete-time timers for Eco mode and automatic shutdown[cite: 1]. Designed a ventilated enclosure and sensor housing in SolidWorks[cite: 1].
